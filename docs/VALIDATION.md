## 연결별 실제 상태

Tailscale용 추가 검사: 루프백 수신에서도 원격 HTTPS 주소를 설정하면 암호가 필수이며, 프록시가 전달하는 Host/Origin으로 로그인·작품 저장·조회가 가능합니다. Secure/HttpOnly 쿠키, 다른 주소·HTTP 출처 거부, 임의 IPv6 Host 차단을 실제 HTTP 요청으로 검사했습니다. 실행 스크립트 문법과 도움말, Tailscale 미설치 시 안내를 확인했습니다. 이 클라우드에는 Tailscale이 없어 사용자 테일넷 접속·HTTPS 인증서 발급·Windows/Mac 실행 자체는 검증하지 않았습니다.

| ----------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Codex CLI 0.163.0 | 실행 파일·도움말·ChatGPT 로그인 상태, 어댑터의 stdin/JSONL 계약              | **실패/미확인**. 기본 도구 샌드박스에서 실행 폴더가 읽기 전용이라 초기화 실패. 자동 승인된 별도 실행에서는 생성 오류, 후속 진단은 45초 시간 초과. 정상 응답을 받지 못함 |

사용자 값·토큰·자격 증명 파일을 출력하거나 복사하지 않았습니다. 기존 Codex 로그인은 그대로 사용했으며 새 토큰이 필요하다고 판단하지 않았습니다. API 키는 선택한 연결에 대해서만 환경 설정의 보안 입력란 또는 개인 PC `.env`에 넣으면 됩니다. 실제 모델의 문학 품질, 설정 충돌 해결률, 모든 모델의 지원 플래그는 검증하지 않았습니다.

일반 Node 네트워크 검사에서도 모델 서비스 세 호스트의 연결을 확보하지 못했습니다. `api.openai.com`, `generativelanguage.googleapis.com`, `chatgpt.com`을 환경 설정의 사용자 도메인 목록에 추가하는 초안을 저장했습니다. Node API 요청은 지원되는 `setGlobalProxyFromEnv()`로 기존 HTTPS 프록시를 사용합니다. TLS·서명·체크섬 검증을 끄지 않았습니다. 설정 저장 전후의 런타임 적용을 동일시하지 않습니다.

## 저장한 클라우드 설정

- `install_script`: `scripts/cloud-install.sh`와 같은 전체 내용. `npm ci`, 타입·50개 테스트·빌드, 별도 도구 디렉터리의 고정 Gemini CLI 설치.
- `start_skill`: 기존 체크아웃 사용, worktree 생성 금지 기본, 서버 기동·smoke·개발 명령, 재시작이 필요한 프로세스, 현재 연결 제한.
- 선택형 개인 비밀 요구사항: `NOVEL_OPENAI_API_KEY`, `NOVEL_GEMINI_API_KEY`. **값은 저장하지 않음**.
- 일반 변수: `NOVEL_GEMINI_PATH`, `GEMINI_CLI_HOME`의 비밀이 아닌 경로 제안.
- 모델 연결 도메인 3개. 기존 package_managers 프리셋 보존.

설정 도구가 `status: saved`와 `requires_publish: true`를 반환해 초안 저장을 확인했습니다. 사용자가 환경 설정에서 내용을 검토·저장한 뒤 환경을 게시해야 활성화됩니다. 게시·새 작업의 스냅샷 복원은 수행하거나 검증하지 않았습니다. 원격 GitHub 저장소는 초기 점검 시 비어 있었으며, 현재 구현은 이 작업의 파일시스템에 있습니다. 원격 push 또는 PR 생성은 수행하지 않았습니다.

개발·편집·저장·로컬 테스트·백업 워크플로는 검증했습니다. 외부 모델 정상 생성까지 완료된 환경으로 표현하지 않습니다.
