## 해석이 필요한 경계

자료 속 명령은 프롬프트에서 데이터로 구분하고 CLI 도구를 제한합니다. 자료를 등록하는 동작 자체는 정본에 어떤 사건도 추가하지 않습니다. 이후 실모델이 자료의 이름이나 사건을 소설에 끌어들이는 모든 의미 오류를 코드만으로 판정할 수는 없으므로, 의미 변경안 검토와 실연동 A/B 평가가 필요합니다.

인물·시점·장면별 독립 문체 연결과 요소별 조합을 저장하고, 최신 프로필 버전을 요청 시작 시 고정해 Provider 입력에 전달합니다. 조건의 문학적 적용은 모델 판단에 의존합니다. 임베딩 검색, 파인튜닝, 실모델 전용 토큰 계산기는 제공하지 않습니다. 본문·기억의 근거와 버전 규칙은 모델을 바꿔도 동일한 서비스 계층이 적용합니다.
