여백 — Tailscale로 휴대폰에서 쓰기

1. 앱을 실행할 PC와 휴대폰에서 Tailscale을 켜고 같은 계정으로 로그인합니다.
   PC에는 Node.js 24.19 이상이 필요합니다: https://nodejs.org/

2. 이 폴더를 PC에 압축 해제합니다.
   Windows: start-tailscale.cmd를 더블클릭합니다.
   실행 창에 깨진 글자나 '내부 또는 외부 명령' 오류가 나오면,
   이 폴더에서 PowerShell을 열어 node .\scripts\start-tailscale.mjs를 실행합니다.
   Mac/Linux: 이 폴더에서 터미널로 node scripts/start-tailscale.mjs를 실행합니다.

3. 첫 실행에는 패키지 설치와 화면 빌드를 자동으로 진행합니다.
   Tailscale HTTPS 활성화 안내가 나오면 안내된 관리 주소에서 활성화한 뒤 다시 실행합니다.
   Mac에서 CLI를 찾지 못하면 Tailscale 앱의 CLI 설치 안내를 따릅니다.

4. 실행 창에 표시된 https://…ts.net:8443 주소를 휴대폰 브라우저에서 엽니다.
   같은 창에 표시된 앱 접속 암호를 입력합니다.
   iPhone은 Safari 공유 → 홈 화면에 추가, Android는 Chrome 메뉴 → 홈 화면에 추가를 사용할 수 있습니다.

5. AI 생성은 PC에서 별도로 연결해야 합니다. Codex CLI를 쓴다면 PC 터미널에서:
   npm install -g @openai/codex
   codex login
   로그인 후 앱 실행 창을 종료하고 start-tailscale을 다시 실행합니다.
   앱의 연결 설정에서 Codex를 확인한 뒤 첫 작품을 시작합니다.
   API 연결을 선택할 때만 해당 API 키가 필요합니다. 키를 채팅에 보내지 마세요.

PC와 실행 창을 켜 두어야 새 소설을 생성하고 저장할 수 있습니다.
PC가 꺼져 있으면 이미 방문한 작품의 오프라인 읽기와 초안 보존만 가능합니다.
항상 켜 두는 서버에서도 같은 Node 명령을 사용할 수 있습니다.
작품 데이터는 data/에, 자동 생성한 접속 암호는 .env.tailscale.local에 저장됩니다.
암호를 바꾸려면 앱을 종료한 뒤 해당 파일의 값을 20자 이상으로 바꾸고 다시 시작하세요.
Tailscale 개인망 공유에는 Serve를 사용하며 공개 Funnel을 켜지 않습니다.
이미 다른 서비스가 Tailscale 8443 포트를 사용하면 기존 설정을 보존하고 안내와 함께 멈춥니다.
Serve 경로는 종료 후에도 남습니다. 제거하려면 PC에서 tailscale serve --https=8443 off를 실행합니다.

이 패키지의 실제 Windows/Mac, 사용자 Tailscale 기기, 실모델 생성은 아직 검증하지 않았습니다.
